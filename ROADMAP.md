# 🗺️ Roadmap

GitTogether's vision and planned features for the next 12 months.

## 📊 Current Status: v1.0.0 (Stable)

## 🎯 Vision

To become the go-to platform for developers to discover meaningful open-source projects, connect with collaborators, and grow their portfolios together.

## 🎁 Feature Ideas (Community Suggestions)

Have a feature idea? [Suggest it here!](https://github.com/rogue-socket/gitogether/discussions)

Popular requests:
1. **Bulk project export** — Export multiple projects to CSV/JSON
2. **Advanced filtering** — Filter by license, last commit date, contributor count
3. **Project comparison** — Compare two projects side-by-side
4. **RSS feeds** — Subscribe to project updates
5. **Browser extension** — One-click project discovery on GitHub

## 🐛 Known Limitations

- Search index updates every 6 hours (not real-time)
- Limited to GitHub projects (GitLab support planned for Q4 2024)
- Mobile app not available (planned for late 2024)
- No batch operations yet (planned for Q3 2024)

## 🏗️ Technical Debt

- Refactor API routes (modularize)
- Add more unit tests (target: >90% coverage)
- Improve database query performance
- Upgrade dependencies (quarterly)
- Implement proper error tracking

## 📈 Success Metrics

We'll track progress by:
- Active users (goal: 10K by Q4 2024)
- Monthly contribution growth (goal: +30% MoM)
- User retention (goal: >70% at 30 days)
- Community contributions (goal: 100+ contributors by EOY)
- Response time (goal: <500ms for 95th percentile)
